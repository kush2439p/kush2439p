I’m a Java and full-stack developer who enjoys building reliable backend systems, practical products, and tools that solve real problems. I like working across the full path from a clean API contract to authentication, persistence, caching, testing, and a useful user experience.

- 🧱 Building with **Java, Spring Boot, REST APIs, Spring Security, JWT, Redis, MongoDB, SQL, JavaScript, and TypeScript**.
- 🌐 Interested in **distributed systems, resilient services, developer tools, and production-quality testing**.
- 🤝 Open to thoughtful backend, full-stack, and open-source collaboration.
